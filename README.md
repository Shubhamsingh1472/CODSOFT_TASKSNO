* **Description:** A tool that generates strong, customizable passwords using letters, numbers, and symbols.

### **Task 4: Rock-Paper-Scissors Game**
* **File:** `task_4_rock_paper_scissors.py`
* **Description:** An interactive game where the user plays Rock-Paper-Scissors against the computer with score tracking.
